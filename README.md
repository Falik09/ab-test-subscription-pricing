# Анализ A/B-теста стоимости Premium-подписки

Учебный проект по продуктовой аналитике приложения для знакомств. Цель — оценить влияние новой стоимости Premium на конверсию и выручку и сформулировать рекомендацию по внедрению.

**Статус: только для приватного просмотра.** Разрешение на публикацию материалов курса пока не подтверждено. Репозиторий необходимо оставить приватным до согласования публикации данных, кода и результатов. Лицензия на распространение материалов курса не предоставляется.

## Данные и методы

В анализе используются шесть CSV с разделителем `;`: пользователи и транзакции групп Test, Control 1 и Control 2. Всего 12 912 пользователей. Источник по информации автора — Karpov.Courses.

Ноутбук содержит 103 ячейки. Проверяются пропуски, дубликаты, пересечения групп, даты платежей и согласованность выручки. Рассчитываются конверсия, ARPU и ARPPU. Используются A/A-проверки, критерий хи-квадрат, интервалы Ньюкомба, тест Уэлча и бутстрэп с 3 000 повторений и фиксированным генератором случайных чисел. Дополнительно изучается чувствительность к повторяющимся транзакциям и крупным покупателям.

## Определения метрик

Конверсия — число уникальных покупателей / все пользователи группы. Premium включает `premium_no_trial` и `trial_premium`. Общий ARPU рассчитывается по `users.total_revenue`; ARPU Premium — выручка Premium из транзакций / все пользователи группы; ARPPU Premium — та же выручка / уникальные покупатели Premium. В пользовательских сравнениях пользователи без Premium-платежей получают нулевую выручку. Суммы указаны в нормированных единицах датасета, валюта не определена.

## Результаты

Проверенные значения и статус полного запуска приведены в `VALIDATION.md`. Конверсия без пробного периода ниже в Test, а статистически убедительного роста выручки исходный анализ не подтверждает. Рекомендация автора — не внедрять новую цену массово до уточнения аудитории и проверки качества данных. Результаты исследовательские и предварительные.

## Запуск

Среда проверки — Python 3.9. Из корня проекта выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jupyterlab
```

В Windows PowerShell для активации используйте `.venv\Scripts\Activate.ps1`.

Поместите шесть разрешённых к использованию CSV из приватного архива в `data/private/`. Откройте `ab_test_analysis.ipynb` и выполните **Restart Kernel and Run All Cells**. Рабочая папка должна совпадать с корнем проекта. Без приватных CSV воспроизвести анализ нельзя; отсутствующие файлы перечисляются в сообщении об ошибке.

Версия для загрузки очищена от выводов ячеек: при локальном запуске показываются отдельные записи пользователей. Перед сохранением в Git снова очистите все выводы. Код также содержит несколько идентификаторов для исследования аномалий — до проверки разрешения весь проект должен оставаться приватным.

## Ограничения

Точный список стран и платёжных систем с новой ценой не подтверждён: основной анализ охватывает группы целиком. Неоднозначные даты, повторяющиеся платежи и расхождения источников требуют проверки. Средняя выручка чувствительна к крупным покупателям. Поправка на два контрольных сравнения не охватывает все исследовательские гипотезы. Отсутствие значимости A/A не доказывает эквивалентность групп или корректность рандомизации. Долгосрочное влияние на удержание, продления и LTV не установлено.
