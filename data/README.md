# Приватные данные

Шесть CSV с разделителем `;` нужно хранить в `data/private/`. Они исключены из Git. Получайте данные только через разрешённый доступ к материалам курса.

## Переименование

- `Проект_3_transactions_test(1).csv` → `transactions_test.csv`: 273 строк данных.
- `Проект_3_transactions_control_1(1).csv` → `transactions_control_1.csv`: 1007 строк данных.
- `Проект_3_transactions_control_2(1).csv` → `transactions_control_2.csv`: 328 строк данных.
- `Проект_3_users_control_2(1).csv` → `users_control_2.csv`: 4264 строк данных.
- `Проект_3_users_test(1).csv` → `users_test.csv`: 4308 строк данных.
- `Проект_3_users_control_1(1).csv` → `users_control_1.csv`: 4340 строк данных.

Изменены только названия, содержимое файлов сохранено побайтово. В таблицах пользователей 13 столбцов, в транзакциях — 8. Связь — по `uid`. Описание полей приведено в начале ноутбука.

Разрешение курса на публикацию не подтверждено. Не загружайте приватный архив, исходные CSV или выполненный ноутбук на GitHub. Репозиторий с кодом и агрегированными результатами тоже оставьте приватным до согласования. `.gitignore` не действует на загрузку через браузер и не удаляет файлы из истории Git.
